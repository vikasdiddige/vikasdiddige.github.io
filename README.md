# Vikas Diddige — professional portfolio

A responsive, dependency-free website prepared for https://vikasdiddige.github.io.

## Preview

Open `index.html` in a browser. No installation or build is required.

## Publish with GitHub Pages

1. Sign in to GitHub as `vikasdiddige`.
2. Create a public repository named `vikasdiddige.github.io`. If it already exists, review its contents before changing it.
3. Upload `index.html`, `styles.css`, and `.nojekyll` from this directory to the repository root, then commit the changes to `main`.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/ (root)**, and save.
6. Visit https://vikasdiddige.github.io after GitHub finishes deployment. Publication may take up to 10 minutes.

Official instructions: https://docs.github.com/en/pages/quickstart

Upload only the website files, not the parent job-search workspace.

## Update content

Edit `index.html` to update your biography, work, experience, education, and contact links. Edit `styles.css` to change presentation. The content is based on the workspace candidate profile; dates, publication links, and downloadable CV are omitted until supplied. Public contact links include the supplied email address and LinkedIn profile.
